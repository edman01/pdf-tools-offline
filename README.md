# PDF Tools Offline

Official website, privacy policy, support documentation, and verified beta screenshots for **PDF Tools Offline** — a private PDF toolkit for iPhone.

All PDF processing runs locally on the device. The app requires no account and does not upload documents, filenames, or usage events to a developer-operated service.

## Product links

- [Product website](https://edman01.github.io/pdf-tools-offline/)
- [Privacy Policy](https://edman01.github.io/pdf-tools-offline/privacy.html)
- [Support](https://edman01.github.io/pdf-tools-offline/support.html)

## Included tools

Compress PDF, Batch Compress, Merge PDFs, Organize PDF, Extract Pages, Rotate Pages, Delete Pages, Add Page Numbers, Images to PDF, and PDF to Images.

Every result can be previewed before it is saved or shared.
