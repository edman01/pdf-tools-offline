Compression

Choosing a compression level

Which level should I choose?

Light prioritizes image quality. Balanced is the recommended starting point for most documents. Maximum makes the strongest size-reduction attempt by rendering each page as an image. If the original is already smaller, the app preserves it.

Why is the result nearly the same size?

The source may already be optimized or mostly contain efficient text and vector content. The app keeps the original when it cannot create a meaningfully smaller valid PDF.

Are estimated sizes guaranteed?

No. Estimates are planning ranges based on the original file and page count. Photos, scans, diagrams, and existing compression all affect the final size.

Does Maximum preserve selectable text?

Not necessarily. Maximum converts pages into images to reduce size. Use Light or Balanced when selectable text and vector detail are important.

How does Batch Compress work?

Open Batch Compress, select multiple PDFs, choose one quality level, and tap Compress. Each file stays separate, and all finished PDFs can be saved or shared together.

Page and image tools

Editing and converting locally

How do I extract, rotate, or delete several pages?

Select a PDF, tap each page thumbnail you want to affect, and use the action button at the bottom. Select All and Clear make larger selections faster.

Can I delete every page?

No. The app keeps the action disabled when every page is selected, because a valid PDF must contain at least one page.

Where can page numbers appear?

Choose the starting number and place the footer at the bottom left, center, or right. Existing page content remains in place.

Which image formats can PDF to Images create?

Choose PNG for sharp text and document pages, or JPEG for smaller photo-heavy images. Every PDF page is exported as a separate image.

How are images placed in an Images to PDF document?

Each selected image becomes one page. The app uses portrait or landscape A4 automatically and preserves the image’s aspect ratio.

Merge and organize

Building the right page order

How do I select multiple PDFs?

Open Merge PDFs and tap Select PDFs. In the iOS Files picker, tap each document you want, then tap Open. All selected PDFs appear in one list.

How do I change the merge order?

Press and drag the reorder handle on the right side of a file row. The number at the left shows its final position.

What is the difference between Merge and Organize?

Merge combines whole documents in file order. Organize opens individual page thumbnails so you can reorder or remove specific pages.

Can I add another PDF after the first selection?

Yes. Tap Add PDFs on the merge screen. Existing files remain in the list, and the newly selected files are added for you to reorder.

Compatibility

Files the app can process

Are password-protected PDFs supported?

Not while locked. Remove the password in the source app, save an unlocked copy, and select that copy again.

What if a PDF is damaged?

The app stops the import and shows an error instead of creating an incomplete output. Try opening the file in another PDF reader and export a fresh copy.

Does the app work with Files providers?

Yes. You can select a PDF from locations made available through the iOS Files picker. Availability depends on the provider and whether the file is accessible on the device.

Privacy and storage

Local by default

Does PDF Tools Offline upload my files?

No. PDF processing happens in the app’s local sandbox. The app has no upload service, account system, advertising, analytics SDK, or tracking SDK. Apple may provide opt-in, privacy-protected App Store diagnostics and aggregate analytics under your device settings.

Where is the finished PDF saved?

After processing, tap Save or Share and choose a destination in the iOS share sheet. The app does not choose a cloud or messaging destination for you.
